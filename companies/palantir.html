Palantir

20 道专属题7 个板块6 道通用题

覆盖岗位

前向部署工程师、前向部署软件工程师、软件工程师、数据工程师、部署策略师、AIP 工程师。

公开报道的面试流程

招聘官电话(约 30 分钟)→ 技术筛查(现场编码或 HackerRank：一道编码题、一条 SQL 查询和一个 API 任务)→ 三轮 60 分钟的 onsite，从分解(decomposition)、学习、编码、再工程、系统设计中抽取 → 招聘经理 轮，会回头考察较弱的环节。分解是标志性的那一轮。

另外还要准备

跨公司通用面试题中标注 Palantir 的题目，分布在 RAG 与检索、Agent 与工具调用、AI 系统设计。

这家公司会问的通用题（6）

  • 设计一个权限感知的检索：用户绝不能看到其在源系统中无权访问的内容。
  • 在生产系统中，如何让 agent 的动作可逆，或至少可审计？
  • 为一个会执行有后果动作的 agent 设计人在环路(human-in-the-loop)…
  • 设计一个文档智能流水线：输入扫描版 PDF，输出结构化字段，规模 1000 万文档。
  • 为拥有数千张表的数仓设计一个 Text-to-SQL 系统。
  • 设计一个 LLM 网关：跨供应商路由、故障转移、缓存、预算与限流。
