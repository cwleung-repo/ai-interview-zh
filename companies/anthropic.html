Anthropic

37 道专属题10 个板块13 道通用题

覆盖岗位

Member of Technical Staff(MTS)、软件工程师(产品 / 基础设施 / API 服务)、研究工程师、研究科学家、应用 AI 工程师、前向部署工程师(Applied AI)、性能工程师(推理与算子)、产品工程师(Claude Code / Claude.ai)。

公开报道的面试流程

招聘官初筛(约 30 分钟，有实质内容、会刷人)→ CodeSignal 式或现场编码测评(约 70–90 分钟，一道实操题分约 4 个递进层级)→ 约五轮的线上现场面试（virtual onsite）：项目深挖、一到两轮编码、系统设计，以及专门的价值观/文化轮。端到端时长：3 周到约 2 个月。部分 MLE 流程现在还包含一轮“AI 协作”轮：现场提供 Claude，考察你如何指挥与验证它。

另外还要准备

跨公司通用面试题中标注 Anthropic 的题目，分布在 LLM 内部机制与架构、推理服务与 GPU 性能、Agent 与工具调用、评估与可观测性、安全安保与负责任 AI、AI 系统设计、编码与数据结构。
