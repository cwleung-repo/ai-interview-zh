34 道专属题8 个板块22 道通用题

覆盖岗位

大模型算法(北斗 / 到店 / 到家)、Agent 应用开发、多模态与文档大模型、搜索推荐大模型。

公开报道的面试流程

校招常见两轮技术面 + HR，社招轮次更多。追问方式非常稳定：为什么这么选、替代方案是什么、怎么验证、剩下 1%–2% 的坏例怎么发现。校招企业页有多名候选人独立反馈“大模型选择题 + 算法 + AI Coding”的组合，官方 Agent 平台强调长任务、Skill / Subagent、跨会话记忆、凭证隔离、沙箱与全链路可观测。

另外还要准备

跨公司通用面试题中标注美团的题目，分布在 LLM 内部机制与架构、推理服务与 GPU 性能、RAG 与检索、Agent 与工具调用、微调后训练与对齐、评估与可观测性、AI 系统设计、编码与数据结构。

这家公司会问的通用题（22）

  • 什么是 KV 缓存？在大规模场景下它对显存有什么影响？请推导公式。
  • 什么是多查询注意力(MQA)和分组查询注意力(GQA)？它们分别牺牲了什么？
  • 什么是多头潜在注意力(MLA)？DeepSeek 为什么要引入它？
  • 解释 RoPE，以及位置插值 / YaRN 如何把上下文扩展到训练长度之外。
  • 什么是混合专家(mixture-of-experts)架构？它如何在不增加 FLOPs …
  • 如何在稀疏检索器(BM25)和稠密检索器之间做选择？什么时候两者都需要？
  • 比较 HNSW、IVF-PQ 与扁平(flat)索引。如何选择？recall@k 会带来…
  • 解释 ReAct 模式，以及相比单纯的思维链(chain-of-thought)…
  • 结构化输出与函数调用(function calling)有什么区别？
  • 什么是 MCP(Model Context Protocol)…
  • 多 agent 编排是如何工作的？它在什么时候会崩溃？
  • 什么能让 agent 循环正确终止？如何限制成本和步数？
  • 什么是 DPO？为什么它在许多实验室取代了基于 PPO 的 RLHF？什么时候在线 RL…
  • 解释 GRPO，以及为什么在大规模下去掉价值网络很重要。
  • 从数学上解释 LoRA 的分解。它为什么有效？如何选择秩 r？
  • 在生产 RAG 系统中，如何检测和度量幻觉？
  • 如何评估一个 agent(相对于单次模型回答)？
  • 设计一个代码助手：仓库索引、上下文组装、编辑应用、评估。
  • 设计一个能执行真实动作、并可升级到人工的客服 agent。
  • 用 NumPy 或 PyTorch 从零实现带因果掩码的缩放点积注意力。
  • 实现多头注意力，然后把它改造成分组查询注意力。
  • 实现一个最小 agent 循环，包含工具分发、错误处理和步数预算。
