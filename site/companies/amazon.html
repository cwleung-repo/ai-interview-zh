Amazon (AWS)

23 道专属题8 个板块6 道通用题

覆盖岗位

应用科学家(I/II/III)、机器学习工程师、数据科学家、软件开发工程师(AI/ML)、GenAI 专家解决方案架构师、应用 AI 工程师(Bedrock、Q、SageMaker)。

公开报道的面试流程

在线测评或电话面 → 4–6 轮的 onsite “loop”，每一轮都锚定领导力准则：两轮编码、一轮 ML 广度、一轮 ML 深度 / 研究深挖或 ML 系统设计、一轮 bar-raiser。应用科学家流程还会加一场研究报告。

另外还要准备

跨公司通用面试题中标注 Amazon 的题目，分布在 LLM 内部机制与架构、推理服务与 GPU 性能、AI 系统设计、编码与数据结构。

这家公司会问的通用题（6）

  • 什么是 KV 缓存？在大规模场景下它对显存有什么影响？请推导公式。
  • 比较张量并行、流水线并行、数据并行、序列并行与专家并行。什么时候要把它们组合使用？
  • 你如何把 LLM 服务成本降低 10 倍？请列举所有可用的手段并排序。
  • 一次没有改模型的发布之后，p99 延迟翻倍了。请讲讲你的排查思路。
  • 设计一个面向 1000 万文档、带每用户权限的企业级 RAG 助手。
  • 用 NumPy 或 PyTorch 从零实现带因果掩码的缩放点积注意力。
