9 道专属题6 个板块6 道通用题

覆盖岗位

Member of Technical Staff、Agent 工程师、基础设施工程师、外派工程师、研究工程师(agent RL)。

公开报道的面试流程

偏重动手构建的快速流程：一轮实操的 agent 构建或调试、一轮基础设施设计、一轮 agent 评估，以及面向客户岗位的一轮外派工程场景。

另外还要准备

跨公司通用面试题中标注 Cognition 的题目，分布在 Agent 与工具调用、评估与可观测性、编码与数据结构。

这家公司会问的通用题（6）

  • 在 agent 循环中，你如何处理工具调用错误、超时和重试？
  • 工具多到什么程度算太多？如何设计 LLM 真的能正确使用的工具 schema？
  • 多 agent 编排是如何工作的？它在什么时候会崩溃？
  • 为什么基准分数提升了，用户却说系统变差了？请列举原因。
  • 如何评估一个 agent(相对于单次模型回答)？
  • 实现一个最小 agent 循环，包含工具分发、错误处理和步数预算。
