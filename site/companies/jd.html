覆盖岗位

大模型算法工程师(零售 / 物流 / 科技)、AI Agent 应用开发、Agent Runtime 与平台工程、商品理解与多模态。

公开报道的面试流程

两到三轮技术面 + HR。平台类岗位的 JD 已经把 Agent Runtime、上下文状态、工具 / 插件注册、Streaming、语义缓存、熔断、Eval / 回放与全链路 Trace 直接写进职责。技术面常把 Java / Go、Redis + Lua、MQ、并发这些后端能力与 Agent 题混在一起考，并且很看重“技术商业化”的落地思路。

另外还要准备

跨公司通用面试题中标注京东的题目，分布在 LLM 内部机制与架构、推理服务与 GPU 性能、RAG 与检索、Agent 与工具调用、微调后训练与对齐、AI 系统设计、编码与数据结构。
