阿里巴巴(淘天、阿里云)

27 道专属题7 个板块15 道通用题

覆盖岗位

淘天 / 淘宝闪购 Agent 算法、阿里云 AI 平台与瓴羊 Runtime 工程、夸克与千问的应用开发、阿里国际(Accio)搜索与云沙箱、钉钉 AI 工程。

公开报道的面试流程

两到三轮技术面 + 资深主管交叉面 + HR。阿里云偏 Runtime、权限与可观测，淘天偏业务链路、AI Coding、并发与线上指标，夸克 / 千问是模型与应用双栈，阿里国际更强调搜索、云沙箱、长任务与成本。现场用 AI Coding 完成功能后人工 Review 已经出现在阿里云的样本里。

另外还要准备

跨公司通用面试题中标注阿里巴巴的题目，分布在 LLM 内部机制与架构、推理服务与 GPU 性能、RAG 与检索、Agent 与工具调用、微调后训练与对齐、评估与可观测性、AI 系统设计、编码与数据结构。

  • 什么是混合专家(mixture-of-experts)架构？它如何在不增加 FLOPs …
  • 解释 prefill 和 decode 两个阶段。为什么 prefill 受算力限制，而…
  • 什么是重排序器(reranker)？何时该用它？交叉编码器(cross-encoder)…
  • 结构化输出与函数调用(function calling)有什么区别？
  • 什么是 MCP(Model Context Protocol)…
  • 多 agent 编排是如何工作的？它在什么时候会崩溃？
  • 在生产系统中，如何让 agent 的动作可逆，或至少可审计？
  • 为一个会执行有后果动作的 agent 设计人在环路(human-in-the-loop)…
  • 什么是 DPO？为什么它在许多实验室取代了基于 PPO 的 RLHF？什么时候在线 RL…
  • 解释 GRPO，以及为什么在大规模下去掉价值网络很重要。
  • 提示、RAG 还是微调：请给出你的决策框架，并附上成本与延迟。
  • 如何评估一个 agent(相对于单次模型回答)？
  • 设计一个面向 1000 万文档、带每用户权限的企业级 RAG 助手。
  • 设计一个代码助手：仓库索引、上下文组装、编辑应用、评估。
