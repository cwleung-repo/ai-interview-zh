公开报道的面试流程

招聘官初筛 → 技术筛查(实操编码，通常是“做个真东西”，而不是 LeetCode)→ onsite：两到三轮编码/实操、一轮领域深度或 ML 轮、一轮系统设计，以及行为/使命契合度。应用 AI 与 FDE 流程还会加一轮客户场景与方案设计。

另外还要准备

跨公司通用面试题中标注 OpenAI 的题目，分布在 LLM 内部机制与架构、推理服务与 GPU 性能、Agent 与工具调用、微调后训练与对齐、评估与可观测性、安全安保与负责任 AI、AI 系统设计、编码与数据结构。

这家公司会问的通用题（12）

  • 什么是 KV 缓存？在大规模场景下它对显存有什么影响？请推导公式。

  • 在 agent 循环中，你如何处理工具调用错误、超时和重试？
  • 为一个会执行有后果动作的 agent 设计人在环路(human-in-the-loop)…
  • 提示、RAG 还是微调：请给出你的决策框架，并附上成本与延迟。
  • 在生产 RAG 系统中，如何检测和度量幻觉？
  • 什么是提示注入(直接与间接)？你的分层防御是什么？
  • 如何防止一个拥有工具访问权限的 agent 通过恶意网页外泄数据？
  • 设计一个面向 1000 万文档、带每用户权限的企业级 RAG 助手。
  • 为面向数亿用户的消费级聊天助手设计服务栈。
  • 实现 O(1) get/put 的 LRU 缓存，然后加上 TTL。
  • 实现一个令牌桶限流器，然后让它分布式化。
