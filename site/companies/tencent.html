腾讯

37 道专属题9 个板块19 道通用题

覆盖岗位

混元大模型算法工程师、AI Agent 应用开发(腾讯云 / 广告 / 会议)、多模态算法工程师、LLM Infra 与推理工程、AIGC 应用工程。

公开报道的面试流程

校招常见两轮技术面 + HR(技术占比很高)，社招 3–4 轮。一面以项目拷打为主、追问很细(为什么这么做、为什么不用端到端方案、用了多少卡与什么并行策略、调参怎么调的)，二面偏系统设计或场景题。混元偏模型与训练，应用岗偏 RAG / Agent，而且 MySQL、Redis、Kafka 这类后端基本功常与 AI 题在同一轮出现。注意同一个岗位可能因为团队调整，实际考察内容完全不同。

另外还要准备

跨公司通用面试题中标注腾讯的题目，分布在 LLM 内部机制与架构、推理服务与 GPU 性能、RAG 与检索、Agent 与工具调用、微调后训练与对齐、多模态语音与音频 AI、AI 系统设计、编码与数据结构。

这家公司会问的通用题（19）

  • 什么是 KV 缓存？在大规模场景下它对显存有什么影响？请推导公式。
  • 解释 FlashAttention。它并没有减少 FLOPs，为什么却更快？
  • 解释 RoPE，以及位置插值 / YaRN 如何把上下文扩展到训练长度之外。
  • 什么是混合专家(mixture-of-experts)架构？它如何在不增加 FLOPs …
  • 什么情况下你会选择 vLLM、SGLang、TensorRT-LLM 还是自研栈？
  • 如何在稀疏检索器(BM25)和稠密检索器之间做选择？什么时候两者都需要？
  • 比较 HNSW、IVF-PQ 与扁平(flat)索引。如何选择？recall@k 会带来…
  • 解释 ReAct 模式，以及相比单纯的思维链(chain-of-thought)…
  • 什么能让 agent 循环正确终止？如何限制成本和步数？
  • 为一个会执行有后果动作的 agent 设计人在环路(human-in-the-loop)…
  • 什么是 DPO？为什么它在许多实验室取代了基于 PPO 的 RLHF？什么时候在线 RL…
  • 解释 GRPO，以及为什么在大规模下去掉价值网络很重要。
  • 从数学上解释 LoRA 的分解。它为什么有效？如何选择秩 r？
  • 提示、RAG 还是微调：请给出你的决策框架，并附上成本与延迟。
  • 视觉语言模型如何把图像送进 LLM：投影器、交叉注意力，还是原生 token？
  • 设计一个代码助手：仓库索引、上下文组装、编辑应用、评估。
  • 设计一个 LLM 网关：跨供应商路由、故障转移、缓存、预算与限流。
  • 为面向数亿用户的消费级聊天助手设计服务栈。
  • 实现一个最小 agent 循环，包含工具分发、错误处理和步数预算。
