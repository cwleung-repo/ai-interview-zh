覆盖岗位

研究工程师、研究科学家、机器学习工程师、软件工程师(ML)、前向部署工程师、应用 AI 工程师(Google Cloud / Vertex AI)、数据科学家。

公开报道的面试流程

招聘官初筛 → 技术电话面(编码，有时含 ML 基础)→ onsite：两轮编码、一轮 ML 领域/广度、一轮 ML 系统设计，以及 Googleyness/领导力。DeepMind 研究工程师流程还会加一轮研究深挖、数学/概率，以及从零实现的一轮；之后是招聘委员会与团队匹配。

另外还要准备

跨公司通用面试题中标注 Google DeepMind 的题目，分布在 LLM 内部机制与架构、推理服务与 GPU 性能、AI 系统设计、编码与数据结构。

这家公司会问的通用题（6）

  • 比较贪婪解码、束搜索、top-k、top-p 与温度采样。各自在什么情况下会失效？
  • 比较张量并行、流水线并行、数据并行、序列并行与专家并行。什么时候要把它们组合使用？
  • 为面向数亿用户的消费级聊天助手设计服务栈。
  • 用 NumPy 或 PyTorch 从零实现带因果掩码的缩放点积注意力。
  • 实现多头注意力，然后把它改造成分组查询注意力。
  • 在 logits 向量上实现 top-k、top-p 与温度采样。
