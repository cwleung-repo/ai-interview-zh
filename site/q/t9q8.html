答案

展开简短答案

SSE 解析要维护一个缓冲区：每次 read 追加到 buffer，按 \n\n 切出完整事件，剩下的半截留在 buffer；每行按 field: value 解析，data 行拼接后用 \n 连接，遇到空行派发事件。不要假设一次 read 就是一个事件。

展开完整答案（要点 + 公式）
  • 处理 \r\n 与 \n 混用；注释行（以：开头）忽略。
  • JSON 跨块时只在完整事件后 json.loads，否则会解析失败。
  • 要有最大缓冲上限，防止恶意服务端不发分隔符导致内存爆。
  • 流结束时要 flush 最后一个未以空行结尾的事件（按规范可不派发，但要处理）。
buf = ''
async for chunk in resp.aiter_text():
    buf += chunk
    while '\n\n' in buf:
        raw, buf = buf.split('\n\n', 1)
        data = '\n'.join(l[5:].lstrip() for l in raw.splitlines() if l.startswith('data:'))
        if data and data != '[DONE]': yield json.loads(data)
