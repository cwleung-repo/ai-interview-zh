答案

展开简短答案

KV 缓存就是一个按层保存的 K/V 张量，decode 时把新 token 的 K/V 追加进去，Q 只有当前 token，注意力对全部历史 K/V 计算。关键是位置索引与缓存长度要对齐。

展开完整答案（要点 + 公式）
  • prefill：一次写入 T 个位置的 K/V；decode：写入第 T 个位置并只取最后一位输出。
  • 缓存形状 [B, H_kv, max_len, dh]，用 length 指针记录有效长度。
  • 采样后把新 token 再喂回去，形成自回归循环。
  • 真实实现要处理 block 分配（PagedAttention）、批次内不同长度与抢占。
for step in range(max_new):
    logits = model(x[:, -1:], kv_cache, pos=cur_len)
    nxt = sample(logits[:, -1])
    x = torch.cat([x, nxt[:, None]], dim=1)
    cur_len += 1
