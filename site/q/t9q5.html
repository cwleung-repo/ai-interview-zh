答案

展开简短答案

LRU 用哈希表 + 双向链表：哈希表 O(1) 定位节点，链表头是最新、尾是最旧，get/put 都把节点移到头部，超容量删尾部。加 TTL 就在节点里存过期时间，读取时惰性删除，并定期清理。

展开完整答案（要点 + 公式）
  • Python 可以直接用 OrderedDict + move_to_end，但要自己处理 TTL。
  • 并发：单锁最简单，高并发要分片（按 key hash 到多个 LRU）。
  • TTL 过期不等于淘汰：过期项在被访问或清理线程扫到时删除。
  • 面试追问：如何做 LRU-K、LFU、或带权重的淘汰。
class LRU:
    def __init__(self, cap, ttl):
        self.cap, self.ttl, self.d = cap, ttl, OrderedDict()
    def get(self, k):
        if k not in self.d: return None
        v, exp = self.d[k]
        if exp < now(): self.d.pop(k); return None
        self.d.move_to_end(k); return v
    def put(self, k, v):
        self.d[k] = (v, now() + self.ttl)
        self.d.move_to_end(k)
        if len(self.d) > self.cap: self.d.popitem(last=False)
