如何防止一个拥有工具访问权限的 agent 通过恶意网页外泄数据？

答案

展开简短答案

假设 agent 一定会被注入，重点限制“注入后能做什么”：工具最小权限、网络出站白名单、把外部内容与指令隔离在不同通道、敏感数据不出沙箱、URL/图片代理防外带、以及对发送类动作强制人工确认与速率限制。

展开完整答案（要点）
  • 数据外泄通道：markdown 图片 URL、链接预览、DNS 查询、工具参数、甚至错误信息。
  • 对策：渲染前过滤外链、图片走代理、禁止任意 URL 抓取、出站只允许白名单域名。
  • 权限分离：读邮件的 agent 不能发外部请求；需要时由另一个受限服务执行。
  • 审计：记录所有出站请求与工具参数，异常模式告警。
