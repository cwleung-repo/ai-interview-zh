答案

展开简短答案

Pre-LN 把归一化放在子层之前，残差路径上是一条干净的恒等通路，梯度可以直达底层，因此训练稳定、对 warmup 不敏感，深层模型才能训得起来。RMSNorm 去掉均值中心化、只除以均方根，少一次减法和求均值，速度更快、效果相当。

展开完整答案（要点 + 公式）
  • Post-LN（原版）在残差相加后归一化，深层时梯度容易爆炸，需要精心的 warmup。
  • Pre-LN 的代价是表达力略降（有研究用 Post-LN 初始化技巧追回），但工程上稳定优先。
  • RMSNorm：y = x / sqrt(mean(x²) + ε) · γ，不减均值、不加偏置；LLaMA 系列默认。
  • 还有 QK-Norm（对 q、k 单独归一化）用于超深模型或低精度训练的稳定性。
LayerNorm: (x - μ) / √(σ² + ε) · γ + β
RMSNorm:   x / √(mean(x²) + ε) · γ
