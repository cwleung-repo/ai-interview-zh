答案

展开简短答案

Text-to-SQL 的难点不在生成 SQL，而在 schema 选择与语义歧义。流程：检索相关表/列（数千张表先裁剪到几十张）→ 生成候选 SQL → 语法/权限校验 → 沙箱执行 → 结果自检（为空/异常时改写）→ 返回带解释的结果。

展开完整答案（要点）
  • schema 检索用表描述 + 列名 + 历史 query 的嵌入；带上主外键与示例值。
  • few-shot 用相似问题的 (question, SQL) 对；方言（Spark/BigQuery）要固定。
  • 安全：只读账号、行级权限、查询超时与扫描量上限。
  • 评估：执行准确率（EX）、结果集匹配、以及人工可用率。
