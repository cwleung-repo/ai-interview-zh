答案

展开简短答案

多头就是把 d 维切成 H 份，各自做注意力再拼接投影。改成 GQA 只需把 K/V 的投影输出改成 H_kv 份，前向时把 K/V 按组 repeat 到 H 份再算注意力，最后仍然拼回 d 维。

展开完整答案（要点 + 公式）
  • Q: [B,T,d] → [B,T,H,dh] → [B,H,T,dh]；K/V 同理但头数是 H_kv。
  • repeat_kv：把 [B,H_kv,T,dh] 沿 head 维重复 H/H_kv 次，再与 Q 对齐。
  • 参数量从 4d² 降到 2d² + 2d·H_kv·dh，KV 缓存降到 H_kv/H。
  • 注意 repeat 会复制显存，性能实现里常用 stride/索引而不是真的 repeat。
q = q_proj(x).view(B, T, H, dh).transpose(1, 2)
k = k_proj(x).view(B, T, Hkv, dh).transpose(1, 2)
k = k.repeat_interleave(H // Hkv, dim=1)   # GQA
out = attention(q, k, v).transpose(1, 2).reshape(B, T, d)
