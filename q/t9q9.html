答案

展开简短答案

先按结构边界（标题、段落、列表、代码块）切，再对超长段落按句子切，最后在块之间加重叠。关键是“边界优先级”：语义单元 > 句子 > 字符，绝不从句子/代码块中间切断。

展开完整答案（要点 + 公式）
  • 用递归切分：分隔符列表从强到弱（\n\n → \n → 。→ 空格）。
  • 块大小按 token 计（不是字符），因为嵌入模型有 token 上限。
  • 重叠只加在相邻块之间，且不要跨越结构边界。
  • 保留 metadata（来源、标题路径、页码），供引用与过滤。
def chunk(text, size=500, overlap=50):
    out, cur = [], ""
    for p in split_by_structure(text):      # headings, code, tables
        for s in split_sentences(p):
            if len(cur) + len(s) > size:
                out.append(cur)             # 先落盘完整块
                cur = cur[-overlap:]        # 只保留尾部重叠
            cur += s
    if cur: out.append(cur)
    return out
