答案

展开简短答案

ReAct 把“思考”和“行动”交替起来：模型输出 Thought → Action（调工具）→ Observation，再继续推理。相比纯 CoT，它能获取外部事实、校验中间结果，把只靠参数记忆的推理变成有证据的推理。

展开完整答案（要点）
  • CoT 的问题是“想得越多越可能编”，没有与外界交互的纠错机会。
  • ReAct 的关键是 observation 进入上下文后触发重新规划，形成闭环。
  • 现代实现多用原生 function calling 而不是文本解析，但循环结构不变。
  • 失败模式：工具描述不清、observation 太长污染上下文、循环不收敛。
