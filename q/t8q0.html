答案

展开简短答案

分层：文档接入（解析/分块/ACL 同步）→ 索引（向量 + 关键词 + 元数据）→ 检索（pre-filter + hybrid + rerank）→ 生成（引用 + 拒答）→ 服务（缓存、限流、trace）。每用户权限在检索前用 metadata filter 强制，10M 文档按租户/密级分片，索引增量更新。

展开完整答案（要点）
  • 接入：连接器拉取文档与权限，解析成块，写入 ACL 字段（tenant_id、group_ids、classification），变更走 CDC。
  • 索引：向量库按 tenant 分区；ACL 用可过滤的字段；为高频过滤字段建倒排。
  • 检索：query 改写 → hybrid 召回 → ACL filter → rerank → 取 top 8，附带来源与更新时间。
  • 生成：要求逐句引用，证据不足时明确说“未找到”，并给出可点击的来源。
  • 非功能：p95 延迟、每租户 QPS、缓存（答案 + 前缀）、审计日志、删除传播。
