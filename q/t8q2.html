答案

展开简短答案

客服 agent = 意图识别 + 知识检索 + 工具调用（查单/退款/改地址）+ 策略引擎（能不能做、要不要审批）+ 人工升级。所有写操作幂等并可撤销，高风险动作强制人工确认，失败时带着完整上下文转人工，而不是让用户重述。

展开完整答案（要点）
  • 对话状态机：识别 → 澄清 → 执行 → 确认 → 关闭；每步记录结构化槽位。
  • 工具：查询类直接调，写入类走 prepare/commit 两阶段 + 幂等键。
  • 升级：置信度低、涉及金额超阈值、用户要求人工、或连续两次失败。
  • 质量：解决率、一次解决率、转人工率、CSAT、以及错误动作率。
