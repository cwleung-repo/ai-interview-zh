答案

展开简短答案

最小 agent 循环 = 消息历史 + 工具表 + while 循环：调模型 → 若返回 tool_calls 则逐个执行、把结果以 tool 消息追加 → 否则输出最终答案；同时维护步数预算、超时、错误处理与终止条件。

展开完整答案（要点 + 公式）
  • 工具分发表：name → callable + JSON schema 校验 + 异常包装。
  • 错误要作为 observation 返回给模型，让它自我修正，而不是直接抛给用户。
  • 终止：无 tool_calls、达到 max_steps、或连续重复相同调用。
  • 安全：工具白名单、参数校验、副作用操作需审批、全程 trace。
for step in range(max_steps):
    resp = llm(messages, tools=schemas)
    if not resp.tool_calls:
        return resp.content
    for call in resp.tool_calls:
        try: out = dispatch[call.name](**validate(call.args))
        except Exception as e: out = {'error': str(e)}
        messages.append(tool_msg(call.id, out))
return fallback('step budget exhausted')
