答案

展开简短答案

PII 要分三层处理：输入侧检测与最小化（能不留就不留）、传输与存储加密 + 脱敏（日志/trace 里打码）、训练数据去标识与访问控制。合规上还要支持删除请求与数据保留策略，并对第三方模型调用做数据不落地的约定。

展开完整答案（要点）
  • 检测：正则 + NER 模型，覆盖姓名、电话、证件、地址、医疗信息。
  • 日志脱敏要在写入前做，事后清洗往往已经泄露。
  • 训练数据：去重、去标识、版权与授权审查；记忆化风险要用成员推断测试评估。
  • 跨境与供应商：确认 API 是否用于训练、数据驻留地区。
